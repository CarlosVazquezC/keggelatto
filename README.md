# Keggelatto

PWA para celular Android: un plan de entrenamiento diario con una pantalla "Hoy" y cuatro módulos (piso pélvico, caminadora, pesa rusa, y cara y cuello). Cada sesión marca el ritmo con luz, sonido y vibración. No usa servidor ni cuenta: el registro se guarda en el celular.

- **App:** https://carlosvazquezc.github.io/keggelatto/ (se ve mejor en un celular o con la vista de celular del navegador).
- **Este repo** tiene la versión compilada, sin minificar: `index.html`, `assets/` (el JS, con cada archivo del código fuente en su propio `//#region`, y el CSS), el manifiesto y el service worker.
- **Hecho:** pantalla Hoy, piso pélvico, caminadora y pesa rusa. **En camino:** cara y cuello.
